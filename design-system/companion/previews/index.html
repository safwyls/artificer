Artificer design systems

Artificer Companion

shared world saves, synced from this machine

The player-side half of save sync, wearing reliquary's palette verbatim — one system, two halves. What is different is what the companion knows and the service cannot: which games are installed on this machine, which folder each save lives in, and whether the vault is reachable from here at all. Every screen is built so a player can answer "is my save where it should be?" without opening a folder.

Foundations

  • Shared palette The same eleven tokens reliquary declares
  • Type Georgia, and mono for anything about this machine

Actions

  • Buttons The vault's three, with the companion's verbs

Status

  • Custody chip Six states, from one call — the service's three plus this machine's
  • Window chrome Reachable, as whom, how fresh — said exactly once
  • Activity and Conflicts One read of the vault, filtered two ways
  • Section headers and panel failure A panel that fails, fails alone — and says which

Patterns

  • The games library Linked first, and every tile says what linking costs
  • Worlds, grouped by custody What you hold, what you can take, what someone else has
  • Scan trail Where it looked, and what it found
  • No worlds yet Derived from “nothing linked”, never from a stored flag
  • Update banner A different build is available, and what it will do
