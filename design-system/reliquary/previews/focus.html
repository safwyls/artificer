Focus

One gold ring, offset from the page ground

Focus is visible in exactly one style across the app — a 2px gold ring at 60% offset from ink, the same accent the primary button carries. Declared once on :focus-visible in the base layer, never re-styled per component.

As it renders (the ring is drawn here, not focused)

Rules

  • color-scheme: dark is set on :root — without it a dark page still gets light scrollbars and light form widgets.
  • Never remove the ring without replacing it; the offset exists so it reads on both panel and ink.
