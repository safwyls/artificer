Sidecar agents

One agent sits beside each game server, sharing its install volume. It is what makes a console able to install a game, read a save, edit a config file and stop a server cleanly — none of which a network protocol exposes.

Two modes

ModeWhat it means
supervisorThe agent runs the game itself, as a child process. It owns start, stop, restart, crash recovery and the game's log. This is what provisioning creates.
companionThe game runs in its own container; the agent only shares the volume and serves files. Power control falls back to Docker.

What happens on first boot

  1. The agent checks whether the game is installed — one file it knows to look for.
  2. If not, it runs SteamCMD against the game's app id and waits for it.
  3. It seeds the game's config file: server name, description, passwords, owner id, whatever that game needs, applied once so your later edits stick.
  4. It enforces the settings that must be true for the console to work at all — for Palworld, that means turning RCON and the REST API on with your admin password.
  5. It starts the game, unless the persisted desired state says you last asked for stopped.

Desired state lives in the install volume, so recreating the agent container mid-flight resumes whatever you last asked for rather than silently starting a server you had stopped.

Launch profiles (Dragonwilds)

Dragonwilds ships two dedicated-server builds under one app id. The native Linux build is simple and cannot load mods, so its command verbs stay unavailable permanently. The Windows build under Wine can carry UE4SS, and therefore the dwbridge mod that makes commands possible at all.

Switching between them is a re-download, not a restart, because they come from different Steam depots — so the choice applies at the next start and the agent refuses to decide that timing for you.

The API

Everything is behind one bearer token, generated at provisioning time and stored encrypted by the console. The agent serves power verbs, SteamCMD jobs, the game log, the config file and the save directory. It is not a shell: there are no path parameters, only fixed locations, so a compromised console cannot ask it for arbitrary files.

The agent port (8811) must be published for the console to reach it. A container that does not publish it can be discovered but not adopted — there is no address to reach its agent on.

Updating a game

Use the console's Update action, which runs SteamCMD as a visible job with its output in the UI. The agent refuses to start a game while a job is running, because starting a server whose files are being rewritten is how installs corrupt.
