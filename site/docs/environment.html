Environment variables

All three consoles read the same variables — only the image differs. Agents differ only in their prefix.

Console

VariableDefaultWhat it does
DATA_DIR./dataWhere the database and backup archives live. Set it to the mounted volume.
HTTP_ADDR:8080Listen address.
JWT_SECRET—Signs session tokens. Changing it logs everyone out.
ENCRYPTION_KEY—Exactly 32 characters. Encrypts stored passwords and agent tokens. Never change it.
ADMIN_USERNAME—Seeds the first admin account on an empty database.
ADMIN_PASSWORD—That account's first password. Change it in the UI afterwards.
ANVIL_URLunsetEnables provisioning. Unset means the wizard is simply absent.
ANVIL_TOKEN—This console's token from ANVIL_CLIENTS.
DOCKER_HOSTunsetOptional direct power control over containers this console did not provision. Point it at a socket proxy, never the raw socket.
COOKIE_SECUREfalseSet true once served over HTTPS.
CF_ACCESS_TEAM_DOMAINunsetEnables Cloudflare Access sign-in.
CF_ACCESS_AUD—The application audience tag. Required with the above.
CF_ACCESS_ADMIN_EMAILSunsetComma-separated. These accounts get admin on first SSO sign-in — the lockout rescue.
ANTHROPIC_API_KEYunsetEnables the advisor chat (palcon).
GEMINI_API_KEYunsetAlternative advisor provider. Anthropic wins if both are set.

Sidecar agents

Substitute the prefix for your game: PALAGENT_, WKAGENT_ or FLAMEAGENT_. Provisioning sets these for you; they are listed for hand-built stacks and for reading an existing container.

VariableDefaultWhat it does
*_TOKEN—The bearer token the console authenticates with. Required.
*_MODEcompanionsupervisor makes the agent run the game itself.
*_INSTALL_DIRper game/palworld, /dragonwilds or /enshrouded.
*_ADDR:8811Agent API listen address.
*_APP_IDper gameSteam app to install. Rarely overridden.
*_SERVER_NAMEunsetSeeds the server-browser name.
*_ADMIN_PASSWORDunsetEnforced into the game's config every start.
*_AUTOSTARTtrueStart the game on agent boot, unless a persisted "stopped" says otherwise.
*_STOP_GRACEper gameHow long a signalled game gets before SIGKILL.
*_GAME_ARGSper gameLauncher flags. Overriding opts out of the defaults entirely.

Game-specific additions: PALAGENT_SERVER_DESC (the MOTD); WKAGENT_OWNER_ID and WKAGENT_WORLD_NAME; WKAGENT_LAUNCH_PROFILE plus the Wine settings on the Dragonwilds Wine image; FLAMEAGENT_JOIN_PASSWORD.

Retired names

These were read by earlier builds and are read by none now. A console that boots with one of them set — and without its replacement — logs a warning naming both, because the symptom otherwise is a feature that quietly vanished: no wizard, no explanation.

No longer readSet insteadWhy
ILMARI_URL
ILMARI_TOKEN		ANVIL_URL
ANVIL_TOKEN		The host service is called Anvil now. Same protocol — only the name changed, so the value carries over unedited.
PROVISIONER_URL
PROVISIONER_TOKEN		ANVIL_URL
ANVIL_TOKEN		Provisioner-mode agents are retired; provisioning goes through Anvil. Different protocol — the old URL cannot be reused, see route 4.

Setting both the old and new name is not an error: the warning only fires while the replacement is still unset, so a compose file can carry the old line until you get around to deleting it.
