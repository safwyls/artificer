Your first server

Adding a server has three routes, and the console leads with whichever fits your host. Press + in the server rail to see them.

The three routes

RouteUse it when
AdoptA server is already running on this host that the console does not have a row for. Offered at the top of the dialog whenever discovery finds one. Nothing to type — the token and passwords come back with it.
ProvisionYou want a new server. Anvil creates the container and the agent installs the game.
Add by handThe server runs somewhere this console does not manage. You supply the address and credentials yourself.

The provisioning fields

FieldWhat it does
NameThe display name, and the source of the slug — the container becomes <agent>-<slug> and the data directory <dataRoot>/<slug>.
HostThe address the console and players reach this box on. Prefilled from Anvil's ANVIL_PUBLIC_HOST.
In-game nameWhat appears in the server browser. Defaults to the display name.
PortsProposed clear of every row and container the console can see. Palworld takes four; Dragonwilds publishes a contiguous pair plus the agent; Enshrouded one plus the agent.
Image tagWhich agent build to run. Defaults to latest.
Run asThe container user. Must match the ownership of the data directory — 568:568 on TrueNAS.
Admin passwordGenerated if left blank. Shown once after provisioning, and enforced into the game's config on every start.

Dragonwilds adds one required field with no default: the Owner ID, from the game's Settings screen. The server refuses to start without one, so the wizard refuses too rather than creating something that cannot boot.

What happens after you submit

  1. Anvil pulls the agent image, creates the data directory and starts the container.
  2. The console shows the admin password once. Save it — it is not shown again, though it can be rotated later.
  3. The agent runs SteamCMD. Progress appears on the server card; the Update log carries SteamCMD's own output.
  4. The agent seeds the config file and starts the game.

A first install is several gigabytes, so the card sits on "installing" for a few minutes. If it finishes suspiciously fast and the server then refuses to start, read the not-installed entry — that specific pairing has one cause.

Checking it worked

  • The card shows the agent as reachable and the game as running.
  • The Configuration view can read the game's settings file.
  • Joining from the game client works on the published game port.
